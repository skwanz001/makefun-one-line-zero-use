One original line (78 characters) naming a hilariously useless superpower, entered in make.fun's "One Line, Zero Use: The Useless Superpower Sprint" bounty. `main.py` (standard library only) writes the line to `/output/entry.txt`.

> I can stop time for exactly one second a year, and I always spend it blinking.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (override the directory with `OUTPUT_DIR` for a local run).
